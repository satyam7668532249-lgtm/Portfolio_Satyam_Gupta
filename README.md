## GitHub Pages
1. Create a public repository named `satyam7668532249-lgtm.github.io`.
2. Upload every file in this folder directly into the repository root.
3. Open Settings → Pages.
4. Select `Deploy from a branch` → `main` → `/ (root)` → Save.
5. Visit `https://satyam7668532249-lgtm.github.io/`.

No build step is needed.
